PANDUAN ROLLBACK

Sejak tersambung database terpusat, data tidak lagi hilang saat berganti perangkat atau membersihkan cache — cukup masuk dengan kode akses dan data dimuat dari database. Impor Excel kini dipakai untuk kirim massal (misalnya data lama hasil export) ke database.

Langkah Rollback:

  1. Cari file Excel hasil export sebelumnya (format: DataMustahik_BAZNAS_LLG_YYYY-MM-DD.xlsx)
  2. Klik tab Import / Rollback di atas
  3. Upload file Excel tersebut ke area di atas
  4. Periksa pratinjau data (total baris, valid, duplikat)
  5. Klik "Import → Kirim ke Database"; data ber-NIK sama akan diperbarui (upsert), bukan diduplikasi
  6. Data akan langsung muncul di tabel Daftar Mustahik ✅
💡 Tips: Biasakan export Excel setiap selesai sesi input data. Simpan file di Google Drive atau folder khusus agar mudah ditemukan saat dibutuhkan.
